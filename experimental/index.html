Emulator Tips

  • Real saves work now: use the game's own save menu as normal. NDSWeb mirrors the game's save data (.sav) into your browser every few seconds and restores it the next time you launch the game.
  • Use the download / upload buttons in the play toolbar to export or import a raw .sav file (handy for moving saves to a real console or another browser).
  • Games with have save data stored in your browser. If a game has no in-game save yet but has an old save state, that state is loaded instead.
  • The toolbar save / rewind buttons make and load a quick save state. States are optional extras; your in-game save is the main one.
  • Use the Export Saves button above to back up all your progress as a JSON file.
  • The toolbar auto-hides during play. Click Pin to keep it visible, or hover the top of the screen.
